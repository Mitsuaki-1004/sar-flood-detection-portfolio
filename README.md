# 🛰️ SAR衛星データによる浸水域検出の学習ポートフォリオ

Sentinel-1 SARデータを使って浸水域を検出する手法を、Google Earth Engine上で実装・検証した学習記録です。
2023年7月の九州北部豪雨（福岡県久留米市・筑後川流域）を題材にしました。

> **このリポジトリの位置づけ**  
> 衛星データ解析を学習中の段階で作成したものです。技術的な完成度よりも、SARという技術を理解し、実データで手を動かしてみた過程を記録することを目的にしています。  
> コードの実装にはAIツールを活用しており、処理の意図と仕組みは自分の言葉で説明できる状態を目指しました。

---

## 📌 このリポジトリで取り組んだこと

光学衛星では雲に阻まれて観測できない災害時に、SARが「雲を貫通して地表を観測できる」という特性を活かして浸水域を検出できるのか——これを自分の手で試してみました。

具体的には、災害前後のSentinel-1 SAR画像の後方散乱強度を比較し、急に暗くなったエリア（=水面と推定される領域）を抽出する処理をGoogle Earth Engine上で実装しています。

## 📊 SARで浸水域が検出できる仕組み（学習メモ）

```
水面の特性：
  電波を鏡面反射するため、SAR画像上で非常に暗く映る

検出の仕組み：
  災害前後の画像を比較して、急に暗くなったエリアを浸水域として抽出する

光学衛星との違い：
  台風・豪雨時は必ず曇天になるが、SARは雲を貫通して観測できる
```

実装の流れ：

1. 発災前後のSentinel-1 GRDシーンをGEEから取得
2. dB変換して後方散乱係数を計算
3. 前後の差分を取り、閾値処理で浸水候補エリアを抽出
4. 面積を概算し、`geemap` でインタラクティブに可視化

閾値の設定や前処理（スペックルノイズの除去など）はまだ改善の余地があり、実運用レベルにするには専門家の検証が必要だと認識しています。

## 🛰️ 無料公開SAR と 商用高分解能SAR の違い（理解メモ）

本解析で使用したSentinel-1（無料公開）と、商用の高分解能SARでは、できることに差があります。

| 比較軸 | Sentinel-1（本解析で使用） | 商用高分解能SAR |
|--------|---------------------------|----------------|
| 分解能 | 約10m | 46cm〜1m級 |
| 観測頻度（同一地点） | 数日〜1週間 | コンステレーション化により高頻度化が進行中 |
| 利用コスト | 無料公開 | 商用ライセンス |
| 夜間・悪天候 | 可 | 可 |

発災直後の初動判断には、より高い分解能と観測頻度が求められます。本解析で構築した処理パイプラインは、より高性能なSARデータが入手できるようになった際にも、同じ考え方で応用できるはずだと考えて作っています。

## 💭 この学習を通じて感じたこと

「衛星データ」という言葉を聞いたとき、最初は遠い世界の話のように感じていました。けれど実際に手を動かしてみると、無料公開されているデータと無料の解析環境（Google Earth Engine）だけで、自分の住む地域の災害をここまで可視化できることに驚きました。

データを扱う技術と、それを現場の課題につなげる視点。両方が揃って初めて価値が生まれる——というのが、この学習で得られた一番大きな気づきでした。
